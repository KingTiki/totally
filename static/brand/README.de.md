# Logo-Dateien

[English](README.md)

Die drei Marker-Bilder gehören zum mitgelieferten Logo:

- `marker-green.png`: helle Hintergründe
- `marker-mint.png`: dunkle Hintergründe
- `marker-white.png`: App-Symbol

Der Schriftzug verwendet die lokal ausgelieferte Schrift Caveat Brush; siehe
[Lizenz](../fonts/CaveatBrush-OFL.txt). Zur Laufzeit benötigt die Anwendung weder
externe Schriftdienste noch Design-Quelldateien.
