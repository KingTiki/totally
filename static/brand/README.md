# Logo assets

[Deutsch](README.de.md)

The three marker images are bundled logo assets:

- `marker-green.png`: light backgrounds
- `marker-mint.png`: dark backgrounds
- `marker-white.png`: app icon

The wordmark uses the locally hosted Caveat Brush font; see its
[license](../fonts/CaveatBrush-OFL.txt). The application has no runtime dependency
on external font services or design source files.
